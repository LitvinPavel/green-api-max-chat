# MAX Web Messenger — GREEN-API Client (React + TypeScript)

> Тестовое задание на должность **«Фронтенд разработчик React»** для сервиса **[GREEN-API](https://green-api.com/)**.

Пользовательский веб-интерфейс для отправки и получения сообщений в мессенджере **MAX** (а также WhatsApp/Telegram) с интеграцией через REST API сервиса GREEN-API.

Прототип интерфейса спроектирован по образцу **[web.max.ru](https://web.max.ru/)** (корпоративный веб-мессенджер MAX / VK Teams) с акцентом на простоту, надежность и минималистичный функционал.

## 🛠 Технологический стек

- **React 18** — компонентная архитектура, хуки (`useState`, `useEffect`, `useCallback`, `useRef`, `useMemo`).
- **TypeScript 5 (Strict Mode)** — строгая типизация запросов, ответов API, сообщений и состояний компонентов.
- **Vite 5** — высокоскоростной сборщик и dev-сервер.
- **Lucide React** — легковесные векторные пиктограммы.
- **Vitest** — модульное тестирование бизнес-логики, парсера вебхуков и утилит форматирования.
- **Чистый CSS / CSS Variables** — адаптивная стилизация в дизайн-системе web.max.ru без тяжелых UI-фреймворков.

## 📖 Сценарий работы пользователя (User Flow)

1. **Авторизация в системе GREEN-API**:
   - При первом открытии открывается модальное окно подключения.
   - Пользователь вводит `idInstance` и `apiTokenInstance` из личного кабинета [GREEN-API Console](https://console.green-api.com).
   - Приложение проверяет доступность инстанса через метод `getStateInstance` и сохраняет параметры в `localStorage`.

2. **Создание нового чата**:
   - Пользователь нажимает кнопку **«+ Новый чат»** в шапке левой панели.
   - Вводит номер телефона собеседника (например, `79991234567` или `+7 (999) 123-45-67`).
   - Автоматически формируется `chatId` в формате `79991234567@c.us` и открывается окно диалога.

3. **Отправка текстового сообщения**:
   - Пользователь пишет текст в поле ввода и нажимает клавишу `Enter` (или кнопку отправки).
   - Сообщение оптимистично отображается в ленте со статусом отправки (`pending` -> `sent` / `delivered`).
   - Вызывается метод `SendMessage` сервиса GREEN-API.

4. **Получение ответа собеседника**:
   - Собеседник отвечает в мессенджере MAX или WhatsApp.
   - Фоновый слушатель HTTP API (`useGreenApiPolling`) циклически обращается к методу `receiveNotification`.
   - Входящее сообщение типа `incomingMessageReceived` мгновенно отображается в окне диалога с левым выравниванием баббла.
   - Приложение вызывает метод `deleteNotification`, передавая полученный `receiptId`, подтверждая удаление уведомления из очереди.

## ⚙️ Настройка инстанса в кабинете GREEN-API

Для корректной работы получения сообщений по технологии **HTTP API** в личном кабинете GREEN-API:
1. Убедитесь, что ваш инстанс находится в статусе **«Авторизован»** (`authorized`).
2. В разделе **«Настройки инстанса»**:
   - Поле **URL для отправки уведомлений (webhookUrl)** должно быть **пустым** (не заполнено), чтобы уведомления складывались в очередь HTTP API;
   - Опция **«Получать уведомления о входящих сообщениях (incomingWebhook)»** должна быть включена (**Да**).
